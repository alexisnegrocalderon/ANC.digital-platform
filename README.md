# ANC.studio

Landing page de Negro Calderón — sitios web de alto impacto para marcas con identidad.

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger + Lenis (smooth scroll)

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
